# Интеграции — интерактивный тренажёр

**Открыть: https://andreypol1991.github.io/integrations-trainer/**

Одностраничное приложение для обучения межсистемным интеграциям: способы взаимодействия,
HTTP, REST, SOAP, gRPC, форматы данных, идемпотентность и работа API с базой данных.
Всё интерактивно, работает целиком в браузере — ничего устанавливать не нужно.

Парный тренажёр: [«Проектируем интеграцию»](https://andreypol1991.github.io/integration-design-trainer/) —
там то же самое, но с другой стороны: даны таблицы в базе, и нужно спроектировать API самому.

## Механики

- **Направленный маршрут**: кнопки «Дальше →», галочки ✓ на пройденных вкладках, возврат на последнюю вкладку
- **Живой глоссарий**: термины подчёркнуты пунктиром в текстах — наведи и увидишь определение
- **Прогресс**: 93 балла суммарно, сохраняется в браузере (localStorage)
- **Сдача результатов**: в конце генерируется код с результатом — его нужно отправить преподавателю

## Как пользоваться

Просто открыть ссылку выше. Прогресс сохраняется в этом же браузере, так что проходи с одного
устройства. Тема светлая/тёмная — из системы, переключается кнопкой ◐.

Можно и офлайн: скачать `index.html` и открыть двойным кликом.
